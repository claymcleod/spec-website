WDL supports a variety of expressions for computing values within tasks and workflows. These include literal values, arithmetic and logical operators, conditional (if-then-else) expressions, function calls, member access, indexing, and string interpolation. Expressions may appear on the right-hand side of declarations, within command blocks (as expression placeholders), and in output sections. The subsections that follow describe each category of expression in detail.
